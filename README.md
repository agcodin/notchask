# NotchAsk

Your MacBook's notch, now it thinks. NotchAsk turns the notch into a Dynamic Island with an AI that can see your screen, plus live activities, media controls, a volume & brightness HUD, fan control, focus timers and more.

**Website & download:** https://agcodin.github.io/notchask/

- Ask about anything on screen (Claude, ChatGPT, Gemini, or local models via Ollama)
- Secrets are blacked out on-device before anything is sent to a cloud model
- Under 1% CPU

Requires macOS 14 or later on Apple silicon. Download the latest build from [Releases](https://github.com/agcodin/notchask/releases/latest).
